# Corrupted! — нотатки для Claude Code

Династична стратегія про корупцію (ПК + iOS/Android), TypeScript + React + Vite. Автор і дизайнер — Макс; спілкуємося українською. Загальний опис коду — у `README.md`.

## Фокус зараз

**Доводимо до ладу Епоху I повністю** (механіки, баланс, візуал, лор), і лише потім переходимо до наступної епохи. Епохи II–VII не чіпаємо, хіба що щось ламається.

План робіт: документ «Corrupted! — Епоха I: баланс і потік» (https://claude.ai/artifact/EWrEPJPgEiw2Lzzru7CbNN). Кроки:
1. ✅ Інструмент балансу `npm run sim:goals`.
2. ✅ Економіка, маєток як покупка, ліміт міських ходів, ранги міста-держави, Дож (гілка `era1-balance`, PR #1).
3. ⏭ **Дешевий потік:** сходинки до мети життя на ранку (зі штампом і заголовком у газеті при кожному кроці); чутки про ревізора/обшук у газеті за рік до обшуку; коротший вечір (чорна книга одним екраном, «як торік» за замовчуванням, інші сторінки розгортаються лише коли там щось змінилося).
4. Вершина з лору: кампанія дожа у Великій раді (магнати як голоси; шлюб/підкуп суперника важать); Дож зараз 13% — тримати в 10–15%.
5. Контент: ✅ **колода документів** (13 схем, 20 рішень, 8 арок-продовжень, листи від можновладців) — див. «Колода документів» нижче. Ще треба: доручення покровителя, великі події раз на ~5 років, більше карток під пізні роки.
6. Полірування: баги з QA-звіту нижче, плейтест людьми.

## Команди

```bash
npm ci
npm run dev          # гра: http://localhost:5173 · консоль розробника: /?dev
npm test             # 49 тестів, разом із паритетом з HTML-прототипом
npm run sim:goals    # шанси мет життя в Епосі I (уважний бот під кожну мету)
npm run build        # типи + збірка в dist/
```

Швидко перевірити число без правки коду: `RULES='{"estate":{"price":5000}}' npm run sim:goals`.

## Правила роботи з кодом

- **Усі числа балансу — у `src/engine/rules.ts`**, посади Епохи I (ціна, множник, ліміт банку, назви) — у `src/data/eras/era1.json`.
- **Тест паритету** (`test/parity.test.ts`) грає ядро крок у крок проти HTML-прототипу, але на **старих числах прототипу**. Коли міняєш число в `RULES` чи в посадах Епохи I, запиши стару величину прототипу в `PROTOTYPE_PATCH` (у `rules.ts`), інакше паритет зламається. Нова механіка, якої немає в прототипі, має вимикатися з `PROTOTYPE_PATCH` (як `estate.on: false`, `cityMoves.base: 1e9`). Перейменовані рядки прототипу мапляться в `REWORD` / `REWORD_RE` у тесті.
- **`src/data/eras/era1.json` правиться вручну** (зберігай формат: `json.dumps(..., ensure_ascii=False, indent=1)` + `\n`). `npm run extract` більше НЕ запускати: він перезапише ручні правки лору. `strings.base.uk.json` — відступ 2.
- **Рядки:** `{name}` — підстановка, `{пішов|пішла}` — форма за родом (передай `g` у `S(...)`). Джерело рядків Епохи I — `era1.json` (`strings.base.uk.json` синхронізовано з ним). Отто для героїні — «дівер»: `kinFor` у `text.ts` (застосовується в `docsFor`, ролях спільників, чорній книзі). Відмінки суперників — `rivalCase`, рід власника — `ow` у `city.ts`.
- **Ядро чисте:** кожна дія `(state) → новий state`, інтерфейс нічого не рахує сам. Випадковість детермінована (seed у стані).
- **Колода документів (Епоха I)** — `src/engine/deck.ts`, картки в `era1.json` → `deck` (`schemes`, `choices`). Щороку на початку року (`dealYear` у `signForm`/`sleep`/`pickHeir`) роздається 1 схема й 1 рішення (від Сенатора 2) серед карток, чиї `cond` виконуються (ранг, роки служби, шкали, прапори `flag`/`noFlag`, дитина `kidAge`, маєток, злість суперника `rivalHeat`), за вагою `w`, без повторів, доки придатні картки не вичерпаються. Відповідь може ставити прапори (`set`), повертати продовження через N років (`then` → картка з `arc: true`, яку випадково не роздають) і змінювати злість/вплив можновладця (`riv`). Прапори `votes_*` додають `campaign.pledgeVotes` голосів у Великій раді. Листи від можновладців — `who: {kind: 'rival', id}`. Нові картки дописуються в `era1.json` вручну; після змін — `npm run sim:goals -- 600`. Колода вимикається `RULES.deck.on` (паритет грає з вимкненою).
- **Місто переходить спадкоємцю** (`inheritCity` у `city.ts`, викликається з `pickHeir` у межах епохи): заклади, наші дахи, фонд, пай і шептуни лишаються; після провалу роду дахи втрачаються. Дім кожного можновладця теж переходить до свого спадкоємця (`RIVAL_HEIRS`: Северин Солонар, Ельза Берг, граф Анатолій): нове ім'я, досьє, відмінки, злість наполовину, вплив ×0.85, шлюбний союз зберігається. Портрети спадкоємців — `public/art/rivals/<id>-g2.jpg` (480×640, оригінали `art/rivals/<id>-g2-src.jpg`), перелічені в `RIVAL_HEIR_PORTRAITS`.
- **Кінець дня вручну (Епоха I):** після останнього документа кабінет показує «Справи дня закрито» (`DayDone.tsx`, денник рішень `dayLog`, залишок ходів на карті) і чекає `endDay`. `RULES.dayEnd.manual`; паритет грає з вимкненим. Епохи II–VII поки переходять у вечір самі.
- **Боти:** `src/sim/bot.ts` — `goalStep` (бот під мету), `cityMove` (міські ходи; `keepClean` не дає витрачати відкладене на мету).
- **Шрифти Епохи I — локально** (`@fontsource`, `src/ui/fonts.ts`; лише кирилиця й латиниця, woff2 вбудовуються в CSS через `vite.config.ts`, тож однофайлова збірка їх зберігає). Епохи II–VII ще з Google Fonts (`LOCAL_FONT_ERAS`).
- Не комітити `tsconfig.tsbuildinfo` (`git checkout tsconfig.tsbuildinfo` перед комітом).

## Ухвалені рішення (лор і дизайн Епохи I)

- Світ: **Порт-Аурум** — місто-держава (прототип — Венеційська республіка) у складі **Ромейської імперії**. Вальдорія — земля й народ, які в наступній епосі стануть державою з Порт-Аурумом у складі (як Венеція після Рісорджименто). Губернатор — імперський наглядач (шкала «Покровитель»).
- **Ранги:** Радник ради → Бургомістр → Сенатор → Прокуратор (жіночі: Радниця ради, Бургомістерка, Сенаторка, Прокураторка). **Вершина — Дож Порт-Аурума**, обирає Велика рада купців і гільдій (для героїні — «Дожеса»; назви жіночих форм Макс ще може змінити).
- **Мети життя:** Маєток на Замковому пагорбі (купити за 5 000 чистими; лишається роду, крім провалу; схованку під підлогою обшук не знаходить; спадкоємцю з маєтком мета зараховується, якщо він його зберіг — без провалу), Мантія прокуратора (посада коштує 5 000), Чисте ім'я (відставка з ризиком < 27), Палац дожа.
- Служба — до 20 років, відставка можлива з 12-го року.
- **Міські ходи:** 3 на рік + 1 за кожен ранг. Міські дії платять з усіх брудних (шухляда → підлога → склад).
- Гра напівархадна: ніяких таблиць в інтерфейсі; елементи UI — реалістичні фізичні предмети на столі епохи (тактильність, вага, текстура).
- **Імператор:** Яромир III з дому Святогорських (портрет `public/art/people/emperor.jpg`, канон зовнішності — `art/STYLE.md`).
- **Три еліти** (`art/LORE.md`, розділ «Три еліти»): суперники — візаві в усіх епохах. Кречетови-Задонські — спадкова аристократія (кров і доступ), Солонари — нова бізнес-еліта (капітал із малого), Берги — інформаційна (продають думку міста). Наш рід — четверта, адміністративна. Новий контент про суперників виходить із цієї концепції; імена мають читатися англомовною аудиторією.
- **Символіка** (`art/LORE.md`, розділ «Символіка»): імперський прапор червоно-біло-жовтий (державний — з гербом у білій смузі); герб — коронований кречет із ключем і якорем (офіційне зображення `public/art/brand/romei-arms.png`); знак **ромейської крони** — Р під короною, логотип `public/art/brand/crown.png` (замість SVG-значка `cr` у шаблоні Епохи I). Вальдорський прапор блакитно-чорно-жовтий (море, земля, сонце) заборонений до Епохи IV (1990): з'являється лише в жандармській хроніці про криївки (`c_flag`, `FLAVOR` у `city.ts`), відкрито ніколи не висить.
- **Панорама ранку/вечора** (`Panorama.tsx`, 10.5 с): тур камери з трьома зупинками (Старе місто → Ринкова площа → Гавань). Вранці ніч світлішає в ранок і ліхтарі гаснуть, коли камера до них доходить; увечері ліхтарник іде площею й запалює ліхтарі, вікна спалахують хвилею. Мешканці — спрайти в техніці самої картини (`public/art/life/*.webp`, 33 шт.: перехожі збоку, екіпажі, групи, що стоять; сирі аркуші — `art/life/`): смуги руху на площі, причалі й набережній, розмір за глибиною, хода з погойдуванням, тінь, нічне тонування; конка, вози, докери, фіакри з ліхтарями, патруль, на кожній зупинці одна репліка міста на записці; гавань завжди отримує репліку про порт. Великий заголовок 3 с, потім табличка вгорі ліворуч.
- **Карта:** без верхньої панелі з назвою; угорі ліворуч стовпчик «пілюль» однакової ширини: ходи, брудні й чисті гроші з логотипом крони; суми від 1 000 скорочено (`fk`: 1.5k, 2.6k). Чотири міські установи (сиротинець, «Вісник», ринок, жандармерія) мають латунний медальйон і золоту табличку, а кільце під ними «дихає», поки там є хід. Орієнтири (собор, ратуша, вокзал) приглушені й без таблички.
- Тон: не моралізаторський і не націоналістично-проповідницький.

## Цілі балансу (перше життя, уважний гравець)

| Мета | Зараз | Ціль |
| --- | --- | --- |
| Маєток | 40% | 35–45% |
| Прокуратор | 38% | 30–40% |
| Чисте ім'я | 40% | 40–50% |
| Дож | 10% | 10–15% |

Також: життя не обривається провалом у 70–80% випадків; перший помітний крок до мети — на 2–3-му році; щороку хоча б одна справжня дилема; життя ≈ 20 хв.
